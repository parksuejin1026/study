# 토익 중간고사 스터디

`index.html`을 브라우저로 열면 실행됩니다. 앱 실행에는 설치, 빌드, 서버, 외부 라이브러리가 필요 없습니다. PDF와 학습 데이터가 함께 있어야 출처 링크가 작동합니다.

## GitHub Pages

배포 주소: https://parksuejin1026.github.io/study/

이 폴더의 `index.html`, `style.css`, `app.js`, `questions.js`, `.nojekyll`과 원본 PDF들을 저장소 루트에 올립니다. 저장소 Settings → Pages에서 Deploy from a branch를 선택하고 `main` 브랜치의 `/ (root)`를 지정합니다. 저장소 이름이 붙는 하위 경로에서도 동작합니다.

## 학습 범위

- 2주차 1교시 5~13쪽 예문의 밑줄
- 3~7주차 1·2교시 ‘기본 단어 다지기’ 예문의 밑줄
- 2주차 2교시 연어구, 문맥에서 다지기, 어휘 목록만 있는 페이지 제외
- 밑줄 색으로 제한하지 않습니다. 하나의 예문에 여러 밑줄이 있으면 빈칸별로 출제합니다. 떨어진 밑줄은 별도 빈칸으로 취급합니다.

원문을 수정하지 않으므로 문법상 어색한 표현도 PDF에 쓰인 대로 나옵니다. 예문은 PDF에서 추출했습니다. 4~7주차 해석은 PDF 수록 해석을 사용하며, 2~3주차 해석과 밑줄 표현의 뜻은 학습용으로 보완했습니다. 보기는 수록된 밑줄 표현에서 자동 구성하므로 교수님의 실제 시험 보기와 다릅니다. 분리된 밑줄은 개별 빈칸으로 유지합니다. 문장 끝의 마침표와 쉼표는 빈칸에 넣지 않습니다.

페이지별 예문 및 빈칸 목록은 `범위검증.md`를 확인하세요. 문제은행의 수와 실제 시험의 35문항은 서로 다릅니다.

## 기록

답안 선택, 오답 메모, 암기 완료 변경은 localStorage에 자동 저장됩니다. 브라우저와 접속 주소별로 기록이 다르므로 다른 기기로 옮기거나 접속 주소를 바꾸기 전에 JSON으로 내보내세요. 시크릿 모드 종료나 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다. 가져오기는 문제별 기록을 병합하며 같은 문제의 기록을 가져온 값으로 갱신합니다.

모의고사는 암기 완료를 제외한 서로 다른 예문 35개에서 뽑고, 50분 타이머를 제공합니다. 35개의 서로 다른 예문이 남아 있어야 시작됩니다. 미응답은 결과에서 별도로 표시하고 재풀이에 포함합니다.

## 데이터 재생성 (제작용)

실행에는 Python이 필요 없습니다. PDF 변경 후 재추출할 때만 `python -m pip install --target .tools pymupdf`, `python scripts/extract.py`, `python scripts/enrich.py`를 순서대로 실행합니다. 보완한 뜻과 해석은 `scripts/curated-ko.json`에 보관합니다. 새 예문이 생기면 이 파일에도 해석과 뜻을 추가해야 합니다. 앱 자체는 외부 서비스를 호출하지 않습니다.
